# Practice Exercises: Loops in Python

Complete all 35 exercises using Python 3. Try solving them before opening `solutions.md`.

## Beginner: `for` Loops and `range()`
1. Print the numbers from 1 through 10 using a `for` loop.
2. Print all even numbers from 2 through 20 using `range()`.
3. Print each character of the string `"Python"` on a separate line.
4. Iterate over a list of five favorite programming languages and print each item.
5. Print the squares of numbers from 1 through 10.
6. Calculate the sum of integers from 1 through 100 using a loop.
7. Print the multiplication table of a number from 1 through 10.
8. Count how many vowels appear in a string.
9. Given a list of numbers, count how many are even.
10. Iterate over a dictionary of three subjects and marks, printing each subject and mark.

## Beginner: `while` Loops and Control Statements
11. Print numbers from 1 through 10 using a `while` loop.
12. Count down from 10 to 1, then print `"Go!"`.
13. Keep adding numbers from 1 upward until the running total reaches or exceeds 100; print the total and last number added.
14. Use `break` to stop printing numbers when the loop reaches 7.
15. Use `continue` to print numbers from 1 through 10 except 5.
16. Write a `while` loop that asks for a fixed secret word until the user enters it. For a non-interactive exercise, simulate guesses from a list.
17. Calculate the factorial of a non-negative integer using a loop.
18. Reverse a string using a loop without using slicing or `reversed()`.
19. Use a loop to find the largest value in a non-empty list without using `max()`.
20. Use a loop and `pass` as a placeholder; explain what `pass` does.

## Intermediate: Nested Loops and Iteration Tools
21. Print a 5-by-5 square of `*` characters using nested loops.
22. Print a right triangle of stars with five rows.
23. Print all pairs `(a, b)` where `a` is 1–3 and `b` is 1–2.
24. Create a multiplication table from 1 to 5 using nested loops.
25. Use `enumerate()` to print each item in a list with a 1-based position.
26. Use `zip()` to print names and scores from two lists.
27. Search a list for a target value using a loop and `break`. Print `"Not found"` using a loop `else` clause.
28. Remove all negative values from a list by building a new list during iteration.
29. Given two lists, count how many positions contain equal values. Assume the lists may have different lengths and compare corresponding positions only.
30. Print a simple number pattern in which row `n` contains the integers from 1 through `n`, for five rows.

## Applied Data Science
31. Given `scores = [82, 47, 35, 91, 68]`, build a list containing only scores of 40 or more.
32. Calculate the mean of a list of numbers using a loop. Handle an empty list safely.
33. Given a list of transactions, count how many amounts are at least 10,000 and calculate their total.
34. Given a list of temperatures, classify each as Cold (below 15), Moderate (15–30 inclusive), or Hot (above 30), and count each category.
35. Given a list of integers, create a frequency dictionary showing how many times each value occurs.

## Self-Assessment
For each exercise, explain the loop's stopping condition, how many iterations it performs, and whether it uses a counter, accumulator, filter, search, or transformation pattern.
