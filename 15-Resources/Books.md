## 1. How to Use This List

You do not need to read every book in this repository. Choose resources that match your current learning stage and career objective.

| Learning stage | Focus | Recommended approach |
|---|---|---|
| Beginner | Python, basic mathematics, statistics | Start with one introductory book |
| Data analyst | SQL, Pandas, visualization, business analytics | Practice with real datasets |
| Data scientist | Statistics, experimentation, machine learning | Combine theory with projects |
| ML engineer | Algorithms, deep learning, software engineering | Build and deploy models |
| AI engineer | Transformers, LLMs, retrieval, evaluation | Study implementation and system design |
| Data engineer | SQL, data modeling, distributed systems | Build reliable data pipelines |
| Researcher | Mathematical foundations and research papers | Study advanced texts and reproduce results |

**Recommendation:** Choose one primary book per topic, complete its core chapters, and implement the concepts before moving to another resource.

## 2. Best Books for Beginners

These books provide a starting point for learners entering data science.

| Book | Author(s) | Best for |
|---|---|---|
| *Data Science for Business* | Foster Provost and Tom Fawcett | Understanding business problems and data-driven decisions |
| *Data Science: A First Introduction* | Tiffany Timbers, Trevor Campbell, and Melissa Lee | Introductory concepts and practical analysis |
| *Python for Data Analysis* | Wes McKinney | Data manipulation with Pandas |
| *Practical Statistics for Data Scientists* | Peter Bruce, Andrew Bruce, and Peter Gedeck | Applied statistical reasoning |
| *An Introduction to Statistical Learning* | Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor | Statistical learning and machine learning fundamentals |

### Suggested starting point

- New to programming: begin with Python fundamentals.
- Comfortable with Python: start with *Python for Data Analysis*.
- Interested in modeling: study statistics before moving into machine learning.
- Interested in business applications: start with *Data Science for Business*.

Book editions and companion resources can change. Check the publisher or official project website before purchasing.

## 3. Python Programming

| Book | Author | Level | Focus |
|---|---|---|---|

| *Automate the Boring Stuff with Python* | Al Sweigart | Beginner | Practical automation and scripting |

| *Effective Python* | Brett Slatkin | Intermediate–Advanced | Python best practices |

### Recommended order

1. Learn syntax, data types, loops, functions, and collections.
2. Practice file handling and exception handling.
3. Understand modules, packages, and virtual environments.

5. Study advanced Python when needed for larger projects.
