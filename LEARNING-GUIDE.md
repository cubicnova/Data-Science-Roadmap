# Learning Guide

## Suggested pace
- Weeks 1–2: Getting Started + Python
- Weeks 3–5: Math & Stats, NumPy, Pandas
- Weeks 6–7: SQL, Visualization, EDA
- Weeks 8–12: Machine Learning
- Weeks 13–16: Advanced ML, Deep Learning
- Weeks 17+: MLOps, Projects, Interview prep

## Tips
- Code along, don't just read
- Build a project after each phase
