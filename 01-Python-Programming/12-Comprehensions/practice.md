# Python Comprehensions — Practice Exercises

Complete the exercises without looking at the solutions first. Try to use a suitable comprehension for each task and keep the code readable.

1. Create a list containing the squares of numbers from 1 through 10.
2. Create a list of cubes for numbers from 1 through 8.
3. Use a list comprehension to select even numbers from 0 through 30.
4. Select odd numbers from 1 through 25.
5. Create a list of the lengths of the words in a given list.
6. Convert every word in a list to uppercase.
7. Strip leading and trailing whitespace from every string in a list.
8. From a list of integers, keep only positive numbers.
9. From a list of words, keep only words longer than five characters.
10. Create a list of numbers divisible by both 3 and 5 from 1 through 100.
11. Use a conditional expression to label numbers from 1 through 10 as 'even' or 'odd'.
12. Convert a list of temperatures in Celsius to Fahrenheit using a comprehension.
13. Create a list containing the first letter of each non-empty word.
14. Build a list of tuples containing each number and its square.
15. Use a comprehension to remove empty strings from a list.
16. Create a set of unique first letters from a list of words.
17. Create a set of unique word lengths from a list of words.
18. Create a dictionary mapping numbers 1 through 7 to their squares.
19. Create a dictionary mapping each word in a list to its length.
20. Transform a dictionary of item prices into prices with 10% tax.
21. Filter a dictionary to keep only entries with values greater than 50.
22. Create a dictionary of names and their uppercase versions.
23. Flatten a list of lists into one list using a nested comprehension.
24. Create all coordinate pairs (x, y) where x and y each range from 0 through 2.
25. From a matrix, create a flat list containing only values greater than 5.
26. Transpose a rectangular matrix using a nested comprehension.
27. Create a multiplication table as a nested list for numbers 1 through 5.
28. Extract all vowels from a sentence, converted to lowercase.
29. Use a comprehension to replace negative numbers with zero while retaining non-negative numbers.
30. Create a list of words that contain the letter 'a' (case-insensitive).
31. Build a dictionary mapping each number from 1 through 10 to 'even' or 'odd'.
32. Use a generator expression to calculate the sum of squares from 1 through 100.
33. Explain in a comment when a generator expression is preferable to a list comprehension, then demonstrate both.
34. Given a list of records (dictionaries) with a 'score' key, extract scores of at least 70.
35. Given a list of names, create a dictionary mapping each distinct name to its character count.

## Challenge

Choose three exercises and solve each one twice: once with a comprehension and once with an ordinary loop. Compare readability and results.
