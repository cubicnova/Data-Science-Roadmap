# Practice Exercises: Data Structures in Python

Complete the 35 exercises using Python 3. Try to solve them independently before checking `solutions.md`.

## Beginner: Lists and Tuples
1. Create a list of five integers and print the first, middle, and last items.
2. Add an item to the end of a list using `append()`.
3. Insert a value at index 2 and print the updated list.
4. Remove a specified value from a list, handling the case where it is absent.
5. Use slicing to get the first three items and the last two items of a list.
6. Sort a list of numbers in ascending order and then descending order.
7. Count how many times a value occurs in a list.
8. Find the index of a value, handling the case where it is absent.
9. Convert a list of five values into a tuple and print its length.
10. Create a one-item tuple and explain why the comma is needed.

## Sets and Dictionaries
11. Convert a list with duplicates into a set.
12. Given two sets, print their union, intersection, and difference.
13. Check whether a value exists in a set.
14. Create an empty set correctly and add three values to it.
15. Create a dictionary for a student with name, roll number, and marks.
16. Read a possibly missing dictionary key using `get()` and a default value.
17. Add a new key-value pair to a dictionary and update an existing value.
18. Iterate over a dictionary and print its keys and values.
19. Remove a key from a dictionary safely.
20. Given a list of words, build a dictionary of word frequencies.

## Intermediate: Strings, Mutability, and Nested Structures
21. Given a sentence, print its lowercase version, split it into words, and count the words.
22. Reverse a string using slicing, then explain why strings cannot be changed in place.
23. Demonstrate the difference between two variables referencing the same list and a separate copy.
24. Given a list of student dictionaries, print each student's name and marks.
25. Given nested lists of numbers, access one inner value using two indexes.
26. Given a dictionary of products and prices, print products whose prices exceed 500.
27. Remove duplicates from a list while preserving the original order.
28. Given two lists, create a set of values that appear in both.
29. Group a list of names by their first letter using a dictionary.
30. Given a dictionary, create a new dictionary containing only entries whose numeric values are at least 50.

## Applied Data Science
31. Given `scores = [82, 47, 35, 91, 68]`, compute the minimum, maximum, and average without using `min()` or `max()`.
32. Given a list of transactions, use a dictionary to total transaction amounts by category.
33. Given two sets of customer IDs, identify IDs present in both sets and IDs unique to each set.
34. Given a list of records containing `name` and `score`, build a dictionary mapping each name to its score.
35. Given a list of dictionaries representing students and their marks, calculate each student's average and build a summary list with the name and average.

## Self-Assessment
For each solution, explain why you selected that data structure, whether it is mutable, and how your code handles missing or duplicate data.
