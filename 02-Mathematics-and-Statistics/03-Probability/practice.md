# Probability — Practice Exercises

Show formulas and assumptions for calculation questions. For simulation tasks, use a fixed random seed so results are reproducible.

1. List the sample space for one toss of a fair coin.
2. List the sample space for one roll of a standard six-sided die.
3. Find the probability of rolling a 5 on a fair six-sided die.
4. Find the probability of rolling an even number on a fair die.
5. Find the probability of rolling a number greater than 4 on a fair die.
6. A fair coin is tossed once. Find the probability of not getting heads.
7. If P(A) = 0.27, find P(not A).
8. Explain the difference between an outcome, an event, and a sample space.
9. Two fair coins are tossed. List the sample space and find the probability of exactly one head.
10. Two fair coins are tossed. Find the probability of two tails.
11. If P(A)=0.4, P(B)=0.5, and P(A intersection B)=0.2, calculate P(A union B).
12. Events A and B are mutually exclusive with probabilities 0.3 and 0.25. Find P(A union B).
13. If independent events have probabilities 0.6 and 0.2, find the probability both occur.
14. Explain why mutually exclusive events with nonzero probabilities are not independent.
15. A die result is known to be greater than 3. Find the conditional probability that it is even.
16. Given P(A intersection B)=0.12 and P(B)=0.3, calculate P(A given B).
17. A condition affects 2% of a population. A test has sensitivity 95% and false-positive rate 5%. Calculate the probability of a positive test using total probability.
18. Using the values in exercise 17, calculate the probability of the condition given a positive test using Bayes' theorem.
19. Define a discrete random variable and provide an example.
20. Define a continuous random variable and provide an example.
21. A random variable takes values 0 and 1 with probabilities 0.7 and 0.3. Calculate its expected value.
22. A random variable takes values 1, 2, and 3 with equal probabilities. Calculate its expected value.
23. For a Bernoulli random variable with p=0.4, calculate its variance p(1-p).
24. Explain what a probability mass function represents.
25. State the assumptions needed for a binomial distribution.
26. A fair coin is tossed three times. What is the probability of exactly three heads?
27. Use Python to calculate the probability of an even result on a fair die.
28. Use Python to compute the expected value for values [0, 1, 2] with probabilities [0.25, 0.5, 0.25].
29. Use a simulation of 10,000 fair coin tosses to estimate the probability of heads.
30. Simulate rolling a fair die 10,000 times and estimate the probability of a result greater than 4.
31. Write a Python function that calculates a complement probability and validates the input is between 0 and 1.
32. Write a Python function that calculates P(A union B) from P(A), P(B), and P(A intersection B).
33. Explain why a positive medical test does not always mean the person probably has the condition.
34. Explain the difference between theoretical probability and an empirical estimate from simulation.
35. Create a small discrete probability distribution in Python and verify its probabilities sum to 1.

## Challenge

Simulate 20,000 trials of rolling two fair dice. Estimate the probability that their sum is 7, compare it with the theoretical probability, and briefly explain any difference.
