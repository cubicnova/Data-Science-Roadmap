## 1. How to Use This Guide

Courses are grouped by topic so that learners can choose a path based on their experience and career goals.

### Difficulty levels

| Level | Description |
|---|---|
| Beginner | No previous experience or only basic programming knowledge |
| Intermediate | Familiarity with Python, data analysis, and fundamental concepts |
| Advanced | Comfortable with mathematical concepts, programming, and model development |

### Course access labels

- **Free learning:** Course content is available without paying.
- **Audit option:** Some platforms provide free access to selected course materials while charging for certificates or graded features.
- **Open resources:** Tutorials, documentation, and learning materials available publicly.

Always check the provider's current terms before enrolling. A free course does not necessarily include a free certificate, instructor support, or every assessment.

## 2. Beginner-Friendly Learning Paths

If you are starting from scratch, use this sequence rather than enrolling in every course at once.

<details>
<summary><strong>Path A: Complete Beginner to Data Scientist</strong></summary>

1. Learn Python programming.
2. Study basic mathematics and statistics.
3. Learn NumPy and Pandas.
4. Practice SQL.
5. Create charts and visualizations.
6. Learn exploratory data analysis.
7. Study machine learning fundamentals.
8. Learn model evaluation and feature engineering.
9. Build end-to-end projects.
10. Learn deployment and basic MLOps.

</details>

<details>
<summary><strong>Path B: Data Analyst</strong></summary>

1. Excel or Google Sheets fundamentals.
2. SQL and database concepts.
3. Python basics.
4. Pandas for data cleaning and analysis.
5. Statistics and exploratory data analysis.
6. Power BI or Tableau.
7. Business case studies and dashboards.
8. Portfolio projects using public datasets.

</details>

<details>
<summary><strong>Path C: AI and Machine Learning Engineer</strong></summary>

1. Python programming.
2. Linear algebra, probability, and statistics.
3. NumPy, Pandas, and scikit-learn.
4. Supervised and unsupervised learning.
5. Model evaluation and tuning.
6. Neural networks and deep learning.
7. NLP, computer vision, or LLMs.
8. APIs, Docker, deployment, and MLOps.

</details>
