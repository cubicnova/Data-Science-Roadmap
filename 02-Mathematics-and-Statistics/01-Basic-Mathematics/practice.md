# Basic Mathematics — Practice Exercises

Show your working for calculation questions. For programming tasks, use Python and test normal as well as edge cases.

1. Evaluate 18 + 6 × 3 using the correct order of operations.
2. Evaluate (18 + 6) × 3.
3. Convert the fraction 3/5 into a decimal and a percentage.
4. Find 22% of 450.
5. A product's price rises from 800 to 920. Calculate the percentage change.
6. A value falls from 250 to 200. Calculate the percentage change.
7. Simplify 4x + 7x - 3.
8. Evaluate 5x - 2 when x = 6.
9. Solve 4x + 9 = 37.
10. Solve 7x - 5 = 30.
11. A ratio is 2:5 and the first quantity is 18. Find the second quantity.
12. If 6 pens cost ₹90, estimate the cost of 14 pens at the same unit price.
13. Calculate 2^6 and 10^3.
14. Simplify 3^2 × 3^4 using exponent rules.
15. Evaluate the square root of 196.
16. Evaluate log base 10 of 10,000.
17. Evaluate log base 2 of 32.
18. Find the slope between points (2, 5) and (6, 17).
19. Find the value of f(3) when f(x) = 4x - 2.
20. Calculate the mean of 5, 7, 10, and 18.
21. Calculate the sum of the integers from 1 through 10.
22. Find the absolute value of -23 and the distance between -4 and 9.
23. Calculate the remainder when 47 is divided by 6.
24. Explain the difference between / and // in Python.
25. Write a Python expression for 12% of 360.
26. Write a Python expression to calculate percentage change from old_value to new_value, noting the zero-old-value case.
27. Use Python to solve 3x + 8 = 29 for x.
28. Use Python to calculate the mean of a list of five numbers.
29. Given a list of prices, use a comprehension to create prices after a 5% increase.
30. Calculate the ratio of 24 to 36 in simplest form.
31. Explain why the logarithm of zero is undefined in the real numbers.
32. Write the formula for the slope between two points and state when it is undefined.
33. A dataset has values 4, 6, 6, 8, and 11. Calculate the mean.
34. Create a Python function that returns the percentage change and handles an old value of zero clearly.
35. Create a Python program that accepts two numbers and prints their sum, product, quotient when valid, and absolute difference.

## Challenge

Choose a small numeric dataset and write a Python program that calculates its mean, range, percentage increase from its minimum to maximum (if the minimum is nonzero), and absolute differences from the mean.
