# Practice Exercises: Conditional Statements in Python

Solve the exercises in order using Python 3 and consistent indentation.

## Beginner: `if` and `if...else`
1. Set `temperature = 34`. Print `"Hot"` if it is greater than 30.
2. Check whether a number is positive.
3. Check whether a number is even or odd.
4. Given `age = 19`, print whether the person is eligible to vote at age 18 or older.
5. Given a score, print `"Pass"` when it is at least 40; otherwise print `"Fail"`.
6. Check whether a number is divisible by 5.
7. Given `username = ""`, print `"Username missing"` when empty.
8. Given two numbers, print the larger one and handle equality.
9. Determine whether a year is a leap year: divisible by 400, or divisible by 4 but not by 100.
10. Print `"Zero"` if a number is zero, otherwise `"Non-zero"`.

## `if...elif...else`
11. Convert a score to A (90–100), B (80–89), C (70–79), D (60–69), or F (below 60). Reject scores outside 0–100.
12. Classify a number as positive, negative, or zero.
13. Classify age as child (under 13), teenager (13–19), or adult (20+).
14. Classify temperature as Cold (below 15), Moderate (15–30), or Hot (above 30).
15. Given a month number, print the days in that month for a non-leap year. Reject invalid months.
16. Check whether a single English letter is a vowel or consonant; handle invalid input.
17. Validate three triangle side lengths, then classify the triangle as equilateral, isosceles, or scalene.
18. Apply a 10% discount to purchases of ₹1,000 or more; print the final amount.
19. Allow entry only if age is at least 18 and the person has an ID.
20. Classify a day name as weekday, weekend, or invalid.

## Intermediate: Nested and Combined Conditions
21. Compare a username and password against fixed sample values; require both to match.
22. Validate a positive year and a month from 1 to 12 using nested conditions.
23. Print the largest of three numbers without using `max()`.
24. Classify a number as divisible by both 3 and 5, by only one, or by neither.
25. Grant access only if an account exists, the user is verified, and the account is not suspended.
26. Check that a list is non-empty before checking whether its first element is `"admin"`.
27. Validate score and attendance values (each 0–100); eligibility requires score >= 40 and attendance >= 75%.
28. Use a conditional expression to set `"Adult"` or `"Minor"` based on age.
29. Count positive, negative, and zero values in a list using a loop and conditionals.
30. Use `pass` as a placeholder in an `if` block and explain its behavior.

## Applied Data Science
31. Classify `scores = [92, 71, 38, 84, 55]` as High (80+), Medium (50–79), or Low (below 50).
32. Count how many temperatures in a list are above 30.
33. Label transaction amounts as `"Large"` if >= 10,000, otherwise `"Regular"`.
34. Flag a record if age is below 0 or above 120, or its email is empty.
35. Build a calculator for two numbers supporting add, subtract, multiply, and divide. Prevent division by zero.

## Self-Assessment
For each answer, explain which condition is evaluated first, what happens when no branch matches, and how boundary or invalid values are handled.
