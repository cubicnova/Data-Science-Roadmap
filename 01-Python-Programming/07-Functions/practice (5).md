# Practice Exercises — 07 Functions

Complete all 35 exercises. Unless printing is requested, return the result so it can be tested and reused.

## 1. Write `greet()` that prints `Hello, Python!`.

**Hint:** Define it with `def`, then call it.

## 2. Write `show_name(name)` that prints the supplied name.

**Hint:** Use a parameter and an f-string.

## 3. Write `add(a, b)` that returns the sum.

**Hint:** Return `a + b`.

## 4. Write `subtract(a, b)` that returns the difference.

**Hint:** Return `a - b`.

## 5. Write `square(n)` that returns the square.

**Hint:** Use `n ** 2`.

## 6. Write `is_even(n)` that returns a Boolean.

**Hint:** Use modulo.

## 7. Write `maximum(a, b)` without using `max()`.

**Hint:** Use a conditional.

## 8. Write `greet(name='Guest')` with a default argument.

**Hint:** Use a default parameter.

## 9. Write `full_name(first, last)` and call it with keyword arguments.

**Hint:** Use `first=...` and `last=...`.

## 10. Write `area_rectangle(width, height)`.

**Hint:** Multiply width by height.

## 11. Write `celsius_to_fahrenheit(c)`.

**Hint:** Return `(c * 9 / 5) + 32`.

## 12. Write `count_vowels(text)` ignoring case.

**Hint:** Count characters in `aeiou`.

## 13. Write `reverse_text(text)`.

**Hint:** Use slicing.

## 14. Write iterative `factorial(n)` and reject negative input.

**Hint:** Multiply integers from 2 through n.

## 15. Write `average(numbers)` and raise `ValueError` for an empty list.

**Hint:** Validate before dividing.

## 16. Write `describe_person(name, age=18)`.

**Hint:** Return a formatted sentence.

## 17. Write `sum_all(*numbers)`.

**Hint:** Use `sum(numbers)`.

## 18. Write `make_profile(**details)`.

**Hint:** Return the dictionary.

## 19. Write `apply_twice(value, function)`.

**Hint:** Apply the function twice.

## 20. Write a lambda that triples a number.

**Hint:** Use `lambda x: x * 3`.

## 21. Sort `(name, score)` tuples by score using a lambda.

**Hint:** Use `key=lambda row: row[1]`.

## 22. Write `remove_empty(strings)` to trim and remove empty entries.

**Hint:** Use a list comprehension.

## 23. Write `safe_divide(a, b)` that raises `ZeroDivisionError` when b is zero.

**Hint:** Check b before dividing.

## 24. Write `is_palindrome(text)` ignoring spaces and case.

**Hint:** Normalize then compare with reverse.

## 25. Write `min_max(numbers)` returning a tuple.

**Hint:** Validate then return min and max.

## 26. Write `percent(part, whole)` and reject zero whole.

**Hint:** Return `part / whole * 100`.

## 27. Write `format_currency(amount, symbol='₹')`.

**Hint:** Format with two decimal places.

## 28. Write `filter_positive(numbers)`.

**Hint:** Use a list comprehension.

## 29. Write `median(numbers)` for a non-empty list.

**Hint:** Sort and handle odd/even lengths.

## 30. Write recursive `sum_to_n(n)` with a base case.

**Hint:** Use `n == 0` as the base case.

## 31. Write `make_multiplier(factor)` returning a multiplying function.

**Hint:** Define and return an inner function.

## 32. Write `clean_columns(columns)` to strip and lowercase each name.

**Hint:** Use `strip().lower()`.

## 33. Write `unique_in_order(items)` preserving first occurrence.

**Hint:** Track seen items and append new ones.

## 34. Write `calculate_stats(values)` returning count, total, and mean.

**Hint:** Return a dictionary; validate non-empty input.

## 35. Write `validate_password(password)` requiring 8 characters and at least one digit.

**Hint:** Use `len` and `any(ch.isdigit() ...)`.
