# Practice Questions: Hypothesis Testing

Try these exercises before checking `solutions.md`. Use Python and SciPy for programming questions.

1. Define a statistical hypothesis and explain the roles of H0 and H1.
2. Write a two-sided alternative hypothesis for testing whether a population mean differs from 100.
3. Write a right-tailed alternative for testing whether a new process increases the population mean above 50.
4. Write a left-tailed alternative for testing whether average waiting time is less than 5 minutes.
5. What is a significance level alpha?
6. Define a p-value in plain language.
7. Why is a p-value not the probability that the null hypothesis is true?
8. Explain the decision rule when p=0.02 and alpha=0.05.
9. Explain the decision when p=0.08 and alpha=0.05. Why should we not say the null is proven?
10. Define a test statistic and a critical region.
11. Write the one-sample t-statistic formula and define each symbol.
12. Explain Type I error with a practical example.
13. Explain Type II error with a practical example.
14. Define statistical power and state two factors that can increase it.
15. Distinguish statistical significance from practical significance.
16. When is a one-sample t-test suitable?
17. When would you choose Welch's independent two-sample t-test?
18. What is a paired t-test, and why is the pairing important?
19. What question does a chi-square test of independence address?
20. What does a Pearson correlation test evaluate, and what does it not prove?
21. Why should an effect estimate and confidence interval accompany a p-value?
22. What is the danger of choosing a one-sided test after seeing the data?
23. Why does running many unplanned tests increase the risk of false discoveries?
24. A test has p=0.04. What decision would be made at alpha=0.01 and why?
25. A test has p=0.001. Does this automatically mean the effect is large? Explain.
26. Use SciPy to perform a one-sample t-test on [12, 11, 13, 10, 14] against a mean of 10.
27. Use SciPy to compare two independent groups using Welch's t-test.
28. Use SciPy to compare paired before-and-after measurements.
29. Use SciPy to perform a chi-square test on a 2x2 contingency table.
30. Use SciPy to calculate Pearson's correlation for two numeric arrays.
31. Calculate a t statistic when sample mean=54, null mean=50, sample SD=8, and n=16.
32. Explain how changing alpha from 0.05 to 0.01 affects the rejection threshold and Type I error risk.
33. Describe two assumptions you should check before using a t-test.
34. Write a short report sentence for a hypothetical significant result without claiming causation.
35. Choose a real-world question, formulate H0 and H1, select a test, and list the results you would report.
