# Practice Questions: Inferential Statistics

Try these questions before checking `solutions.md`. Use Python and SciPy for the programming exercises.

1. Define inferential statistics and contrast it with descriptive statistics.
2. Define population parameter, sample statistic, estimator, and estimate.
3. What is a sampling distribution?
4. Define standard error and write the standard-error formula for a sample mean.
5. Explain the Central Limit Theorem without claiming that all raw data become normal.
6. What is a confidence interval intended to communicate?
7. Interpret a 95% confidence interval using repeated sampling.
8. Define the null hypothesis and alternative hypothesis.
9. What is a significance level alpha?
10. Define a p-value in plain language.
11. Why is a p-value not the probability that the null hypothesis is true?
12. Explain Type I error and Type II error.
13. Define statistical power and give two factors that can increase it.
14. Distinguish statistical significance from practical significance.
15. When might a one-sample t-test be appropriate?
16. When might Welch's independent two-sample t-test be appropriate?
17. What is a paired t-test, and why must the pairing be retained?
18. What does a chi-square test of independence investigate?
19. What does Pearson correlation measure, and what does it not establish?
20. Why should effect sizes and confidence intervals accompany p-values?
21. Why can repeated testing of many hypotheses produce misleading discoveries?
22. A sample has standard deviation 8 and size 64. Calculate the estimated standard error of the mean.
23. A mean estimate is 100 with standard error 3. Compute an approximate 95% normal-based interval using 1.96.
24. A test returns p=0.03 and alpha=0.05. State the conventional decision and one important caveat.
25. A test returns p=0.20. Does this prove there is no effect? Explain.
26. Use SciPy to run a one-sample t-test on [11, 12, 10, 13, 9] against a reference mean of 10.
27. Use SciPy to compare two independent groups with Welch's t-test.
28. Use SciPy to run a paired t-test on before and after measurements.
29. Create a 2x2 contingency table and use SciPy's chi-square test of independence.
30. Calculate Pearson correlation for two numeric arrays and interpret the sign.
31. Simulate repeated samples and plot the distribution of sample means.
32. Use Python to compute a sample mean, sample standard deviation, and standard error.
33. Write a short results statement that includes an effect estimate and p-value without claiming causation.
34. Name three assumptions or design details you should check before interpreting a statistical test.
35. Choose a research question, identify a suitable test, state H0 and H1, and explain what information you would report.
