# Linear Algebra — Practice Exercises

Use hand calculations for the conceptual questions and NumPy for programming tasks. Check array shapes carefully.

1. Identify the scalar, vector, and matrix in three examples of your own.
2. State the shape of a matrix with 4 rows and 3 columns.
3. Write a NumPy array representing the vector [2, 5, 8].
4. Add vectors [1, 3, 5] and [2, 4, 6].
5. Subtract [1, 2, 3] from [7, 8, 9].
6. Multiply the vector [2, -1, 4] by the scalar 3.
7. Calculate the dot product of [1, 2, 3] and [4, 5, 6].
8. Explain why vectors in a dot product must have compatible lengths.
9. Create a 2-by-3 NumPy matrix and print its shape.
10. Given A = [[10, 20], [30, 40]], access the value 30 using NumPy indexing.
11. Add matrices [[1, 2], [3, 4]] and [[5, 6], [7, 8]].
12. Multiply every entry of [[2, 4], [6, 8]] by 0.5.
13. Explain the difference between element-wise multiplication and matrix multiplication.
14. Multiply A = [[1, 2, 3], [4, 5, 6]] by B = [[1, 2], [3, 4], [5, 6]] and state the result shape.
15. State whether a 2-by-3 matrix can multiply a 4-by-2 matrix on the right, and explain why.
16. Find the transpose of [[1, 2, 3], [4, 5, 6]].
17. Write a 3-by-3 identity matrix using NumPy.
18. Compute the matrix-vector product for [[1, 2], [3, 4]] and [5, 6].
19. Express the vector [7, 10] as a linear combination of [1, 0] and [0, 1].
20. Calculate the Euclidean norm of [3, 4].
21. Calculate the L1 norm of [-2, 3, -5].
22. Calculate the Euclidean distance between [1, 2] and [4, 6].
23. Solve 2x + y = 5 and x - y = 1 by hand.
24. Use `numpy.linalg.solve` to solve the system 2x + y = 5 and x - y = 1.
25. Explain why matrix multiplication is not generally commutative.
26. Create a NumPy matrix and extract its second row.
27. Create a 3-by-2 matrix filled with zeros.
28. Create a 2-by-3 matrix filled with ones.
29. Use NumPy to compute the dot product of two compatible vectors.
30. Given a matrix A, verify that transposing it swaps its row and column counts.
31. Build a feature vector and a weight vector, then compute their weighted sum with a dot product.
32. Explain why `A * B` and `A @ B` can produce different results in NumPy.
33. Check whether a 3-by-2 matrix can be multiplied by a 2-by-4 matrix and state the output shape.
34. Write a Python function that returns the Euclidean distance between two same-length vectors.
35. Create a small numerical example of a linear transformation using a 2-by-2 matrix and a vector.

## Challenge

Create a 3-by-3 matrix and a 3-element vector, compute the matrix-vector product, transpose the matrix, and explain the dimensions of each result.
